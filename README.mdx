# G1 API

An unofficial REST API that collects news from **G1** (<https://g1.globo.com/>) and provides structured data through HTTP endpoints.

<a className="g1-badge" href="https://g1api-unofficial.onrender.com/">🔴 Live API</a>
<a className="g1-badge" href="https://g1api-unofficial.onrender.com/docs">📖 Swagger UI</a>

## Features

- Retrieve news from the G1 homepage.
- Search news by title and summary.
- Access article metadata, including publication dates and image URLs when available.
- In-memory caching with a 60-second expiration time.
- Interactive API documentation powered by FastAPI.
- Query parameter validation for news limits.

## Tech Stack

- **Python** — core language
- **FastAPI** — REST API framework
- **Requests** — HTTP requests
- **Beautiful Soup** — HTML parsing
- **Pydantic** — data validation

## API Endpoints

| Method | Endpoint       | Description                     |
| ------ | -------------- | ------------------------------- |
| `GET`  | `/`            | API information                 |
| `GET`  | `/health`      | Health check                    |
| `GET`  | `/news`        | Retrieve news                   |
| `GET`  | `/news/search` | Search news by title or summary |
| `GET`  | `/docs`        | Interactive API documentation   |

### Get News

Retrieve news collected from the G1 homepage.

```http
GET /news?limit=5
```

**Query parameters**

| Parameter | Type    | Default | Constraints |
| --------- | ------- | ------- | ----------- |
| `limit`   | integer | `10`    | 1–20        |

<a className="g1-badge" href="https://g1api-unofficial.onrender.com/news?limit=5">▶ Try this endpoint</a>

### Search News

Search collected news by title or summary.

```http
GET /news/search?q=tecnologia
```

**Query parameters**

| Parameter | Type    | Description                                         |
| --------- | ------- | --------------------------------------------------- |
| `q`       | string  | Search term                                         |
| `limit`   | integer | Maximum number of results (default: 10, range: 1–20) |

<a className="g1-badge" href="https://g1api-unofficial.onrender.com/news/search?q=tecnologia">▶ Try this endpoint</a>

> Search is performed on the news currently available in the API's cache. It does not search the entire G1 archive.

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/nunogues/g1api-unofficial.git
cd g1api-unofficial
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Start the development server

```bash
uvicorn app.main:app --reload
```

The API will be available at:

- **Base URL:** <http://127.0.0.1:8000>
- **Interactive documentation:** <http://127.0.0.1:8000/docs>

## Caching

The API uses an in-memory cache with a 60-second time-to-live (TTL). News data is reused during this period to reduce repeated requests to the source website.

The cache is reset when the application restarts and is not shared between separate server processes.

## Limitations

- News collection depends on G1's website structure and publicly accessible metadata.
- The number of returned articles depends on successful extraction; the API may return fewer results than requested.
- The API does not provide the full text of news articles.
- Availability depends on the hosting service and the source website.
